## 案例 A：载体词误读 → 风格与情感内核错位

**素材**：一首歌词含大量技术术语的歌曲（程序 / 电路 / 执行 等词高频出现）。

**错误路径**：直接对词汇表反应 → 把"程序/电路"这些【载体词】当成主题 → 选了一个纯机械/电路的视觉世界。

**问题**：歌的情感内核不是"电路"，是**一个执行体渴望被使用、被爱、被关掉就是死**的孤独；
机械世界把"情感"做没了，只剩"设定"。

**正确路径**：识别载体词（术语）→ 追问它象征什么 → 用情感内核选风格 → 机械语言只是**承载方式之一**，不是主题。

## 案例 B：字面词抓取 → 世界观窄化

**素材**：一首歌词反复出现时间/循环相关词的歌曲。

**错误路径**：抓字面词 → 选了一个"钟表"主题的世界观。

**问题**：歌的核心是**悔恨 / 循环的惩罚 / 想被记住**；"钟表"只是它借用的一个意象，
把整片做成钟表 = 把手段当成了目的。

**正确路径**：字面词 → 追问它在歌里承担什么情绪 → 世界观应服务于"悔恨与循环"的情感，
钟表可以是其中一层，但不是全部。

---

## 共同规律（可迁移）

```text
1. 术语/名词密集 ≠ 该领域的视觉风格；
2. 字面词是【线索】，不是【答案】；
3. 风格选择必须回答"它如何承载主题"，答不上就是错配；
4. 最危险的情况：字面直译看起来"很贴"——那正是没读懂的时候。
```
