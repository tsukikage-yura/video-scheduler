# 技法配方（Technique Recipes）

> video-scheduler v0.1.0 · 配套 `style-catalog.md`。

> **为什么存在**：风格目录给了"这种风格该有什么特征"，但**没给"代码怎么画出来"**。
> 动画14 选了「铜版天文钟·双色套印错版」，却退回画细线几何——因为没人告诉它铜版雕刻怎么用 Canvas 画。
> 本文件把**风格特征 → 渲染技法**逐条翻译，扩展/组合风格前先查这里有没有配方；
> 没有配方的风格，先补配方再选（否则必然退回通用线框）。

## 0. 通用渲染原语（所有配方的地基）

```text
填充 vs 线框     fill() 给体量；stroke() 给轮廓。只有 stroke 没有 fill = 线框图（最常见的失败）
渐变             createLinearGradient / createRadialGradient —— 给明暗与体积
多层叠加         globalAlpha + 多次绘制同一形状（错位/偏移）= 印刷/套印/辉光
混合模式         globalCompositeOperation: multiply(加深) / screen(提亮) / overlay(对比)
裁剪             clip() —— 把纹理限制在形状内（材质贴合的通用手段）
路径曲线         bezierCurveTo / quadraticCurveTo —— 有机形态的唯一出路（线框风格可不用）
噪声扰动         vnoise(x,y,t) 扰动顶点/透明度 —— 手作感、纸张、沸腾
颗粒/纹理        drawImage(噪声图) + 低 alpha + multiply —— 几乎所有"质感"风格都需要
```

**铁律**：如果一个风格"看起来有质感"，那一定是 **fill + 多层 + 混合 + 纹理** 的组合，
**不是** stroke 描边能达成的。纯线框 = 没有质感。

## 1. 印刷 / 雕版类（最常被选、最容易翻车）

### 铜版雕刻 Engraving / Copperplate
```text
核心 = 用【密集平行线】代替填充（不是描边轮廓！）
1. 把要画的形状作为裁剪区（clip）
2. 在裁剪区内画密集平行线：间距 1.5~3px，角度随形体走（受光面线疏、背光面线密）
3. 交叉影线（cross-hatch）：暗部叠加第二组反方向线，形成更深的调子
4. 边缘加深：形状边缘用更密的线 + 更粗的线，形成"刻痕"感
5. 底色用暖黄纸色（#e8dcc0 类），线用深褐（#3a2a1a），不要纯黑
6. 加纸纹颗粒（multiply，alpha 8~15%）
关键：线的密度就是明暗。密度=1/间距。稀疏→亮，密集→暗
```

### 双色套印错版 Misregistration / 2-color Print
```text
1. 同一形状画两遍：第一遍颜色 A（如靛蓝），第二遍颜色 B（如朱红）
2. 第二遍整体偏移 2~4px（随机方向，但每帧保持稳定，不要抖动）
3. 两遍都用 multiply 混合 → 重叠处自然变成第三色（套印感）
4. 可加轻微旋转偏移（0.3~0.8°）更像手工套印不准
5. 加纸张纹理 + 边缘轻微溢墨（形状外扩 1px 的浅色）
```

### Riso 孔版叠印 Riso Duotone
```text
1. 限 2~3 色（荧光粉 + 蓝 + 黄，或单色 + 黑）
2. 每个色版独立：形状 + 偏移 + multiply
3. 颗粒噪声必须明显（Riso 的标志）：alpha 15~25% 的粗颗粒
4. 色版重叠处出现深色（multiply 自然产生）
5. 避免渐变——Riso 是平涂 + 颗粒
```

### 蓝图 / 工程制图 Blueprint
```text
1. 深蓝底（#1a3a5c 类）+ 白/青线（负片感）
2. 线要"技术制图"：等宽细线 + 尺寸标注（箭头 + 数字）+ 剖面线（45° 平行线）
3. 网格辅助线（很淡，alpha 5~10%）
4. 标注文字用等宽字体，小号，密度高
5. 关键：要有"图注"——引线 + 编号 + 图例，这才是工程图不是线框画
```

### 活字排版 Letterpress
```text
1. 字为实体：fill 字 + 压印阴影（字下方偏移 1~2px 的暗色）
2. 油墨不均：字内用噪声纹理 multiply（alpha 10~20%）
3. 纸张底 + 纤维纹理；边缘可有轻微墨晕
4. 字距紧、行距小（铅字排版特征）
```

## 2. 仪器 / 机械类

### 天文钟 / 仪表盘 Astronomical Clock / Instrument Dial
```text
1. 多层同心环：外圈刻度（60 格，每 5 格长）、内圈数字、中心指针
2. 金属质感：径向渐变（中心亮、边缘暗）+ 环形高光（1px 亮弧）
3. 雕刻感：刻度线用"刻痕"画法（暗线 + 旁 1px 亮线 = 凹槽）
4. 磨损：用 vnoise 让部分刻度缺失/变淡（wear 参数）
5. 指针带阴影（偏移 2px 的暗色）→ 有厚度
```

### 擒纵机构 / 齿轮 Escapement / Gear
```text
1. 齿轮 = 圆 + N 个齿（齿用 path 画梯形，不是三角）
2. 齿间阴影：齿根处加暗色扇形 → 立体
3. 中心孔 + 辐条（4~8 根，用线 + 宽度渐变）
4. 金属渐变：径向（中心 #c0a060 → 边缘 #604020）
5. 转动时齿要有"咬合"停顿（不是匀速）
```

### 示波器余辉 Oscilloscope Persistence
```text
1. 磷光绿底（#0a1a0a）+ 亮绿轨迹（#40ff80）
2. 余辉 = 不每帧清屏，而是画一层半透明黑（alpha 0.08~0.15）覆盖 → 轨迹自然衰减
3. 双迹：两条波形，相位差，颜色略不同
4. 网格 + 刻度 + 通道标签（CH1/CH2）
5. 波形用 bezier 平滑连接采样点（不是折线）
```

## 3. 古典绘画类

### 烛光 / 明暗对照 Caravaggio / Chiaroscuro
```text
1. 大面积深色底（不是纯黑，#1a1410 类暖黑）
2. 单一强光源：径向渐变（暖白 → 透明），光锥明显
3. 受光面 fill 暖色，背光面几乎融进背景（对比极强）
4. 边缘光（rim light）：形状一侧 1~2px 亮边
5. 关键：形状要"从黑暗中浮现"，不是画在亮底上
```

### 解剖学图谱 Anatomical Plate
```text
1. 米黄纸底 + 褐色线（铜版感）
2. 结构用交叉影线表现体积（见铜版雕刻配方）
3. 标注引线 + 拉丁文小字 + 编号
4. 多个"图版"排列（plate 1/2/3），每版一个部位
5. 加磨损/污渍（vnoise 低 alpha 斑块）
```

### 彩色玻璃 Rose Window
```text
1. 放射状分区（12~24 瓣），每瓣独立填色
2. 铅条：瓣间 2~3px 深色线（#1a1a1a）
3. 玻璃质感：每瓣内径向渐变（中心亮）+ 高光
4. 透光效果：screen 混合的亮斑叠在玻璃上
5. 中心花窗 + 外围环形，层次分明
```

### 金箔祭坛 Gold-leaf Altarpiece
```text
1. 金底：暖金渐变 + 细密斜纹（金箔拼接感）
2. 金箔反光：随时间缓慢变化的亮斑（screen 混合）
3. 主体用深色勾勒（金底上的人物是暗色剪影 + 少量填色）
4. 分格（polyptych）：多个画面格 + 金色分隔框
```

## 4. 材质 / 触感类

### 纸张纤维 Paper Fiber
```text
1. 底：暖白/米色 + 长纤维噪声（方向性噪声，不是白噪）
2. 纤维用短线段随机散布（每帧稳定，用 hash 而非 random）
3. 边缘毛糙：形状边缘用噪声扰动
```

### 墨渍扩散 Ink Bloom
```text
1. 墨滴 = 多层同心不规则形状（每层用噪声扰动半径）
2. 由内到外：深色核心 → 中调 → 淡色晕开边缘
3. 扩散动画：半径随时间增大 + 边缘抖动（boil）
4. 纸张吸收感：边缘比中心更淡（径向 alpha 渐变）
```

### 沙画 / 骨灰流 Sand & Ash
```text
1. 用粒子系统（数千小点）代替连续形状
2. 粒子有重力 + 摩擦，堆积成形状
3. 边缘松散（粒子密度渐变），不是硬边
4. 背光：粒子在暗底上发亮（screen 混合）
```

### 蜡封 / 印章 Wax Seal
```text
1. 不规则圆形（噪声扰动轮廓）+ 内凹阴影
2. 红色蜡质：深红底 + 高光斑 + 边缘半透明
3. 印纹：凹陷的符号（暗线 + 亮线成对 = 凹凸）
4. 压印动画：先变形后回弹（squash）
```

## 5. 图层 / 错位类（通用手段）

### 双图层错位 Two-layer Misregistration
```text
1. 同一内容画两遍，第二遍偏移（2~6px）+ 不同色
2. multiply 混合 → 重叠区变深
3. 偏移量可随时间变化（模拟印刷机抖动）但必须确定性
4. 用途极广：套印、色差、重影、记忆/回忆（第二层=过去）
```

### 银盐负片 Silver Negative
```text
1. 反相：亮处变暗、暗处变亮（可用 invert 或手动画反相）
2. 高对比 + 银盐颗粒（粗颗粒噪声 alpha 15~25%）
3. 边缘光晕（暗角 vignette + 亮边）
4. 褪色：整体降饱和 + 偏暖/偏青
```

## 8. 构图与深度（实验验证，2026-10-10 绘制实验 e089-e095）

### 8.1 "精致"贵在安排，不在画得多细

同一套形状代码，只改 6 个参数：A 面板像教学示例，C 面板像 PV 分镜。
**构图应做成可参数化的槽位（slot），而不是重画一遍。**

### 8.2 深度的公式（5 个变量必须同时动，缺一就塌）

```text
向天空色混合   72% → 0%（越远混合越多）
明度           高 → 低
饱和度         低 → 高
细节密度       无 → 有
描边           无 → 有
```

- **雾带（haze）被低估最多**：两层之间插一条垂直渐变矩形（3 行代码），
  纯色块叠加立刻从"剪纸拼贴"变成"有空气"；
- **人眼主要靠对比度判距离，不是靠大小**——把前景压成近乎纯黑，比把前景画大有效得多。

### 8.3 轮廓光（rim light）不需要任何光照计算

```text
1. 主体画进离屏 canvas → getImageData 取 alpha
2. 逐行 run-length 拼成 Path2D（剪影 sil）
3. fill(sil ∪ translate(sil, d), "evenodd") 并 clip 回 sil
   → 差集天然就是"背对偏移方向那一侧"的月牙（光该在的地方）
4. 3 层即可：3px 白芯 / 8px 金 / 16px 橙（alpha 0.92/0.42/0.20）
```

**推论（重要）**：剪影 + 轮廓光把"造型辨识度"和"细节量"**解耦**了——
主体内部一个细节都不画，观众仍能读出骑士。
→ **先做剪影测试：剪影读不出的角色，加多少细节都救不回来。**

### 8.4 引导线必须收于一个"值得看"的终点

- 线收在空处比不收更糟；
- 消失点偏右 60% 比正中更有行进感；
- 栅栏/树列这类重复元素是**免费引导线**（间距按透视压缩即可）；
- 主角视线是最强引导线。

### 8.5 极端偏心 ≠ 随便放

主体必须被"钉"在一个可解释的位置，否则读成"画歪了"。
**主体尺寸是最便宜的情绪开关**：同一个城堡，0.66 倍 = 宏伟，0.30 倍 + 大留白 = 孤独。

### 8.6 验收方法（两个独立步骤）

```text
缩到 600px 宽还好看 → 构图过关（构图问题在小尺寸放大）
原图看细节        → 细节过关（细节问题在小尺寸消失）
```

### 8.7 性价比排序（预算有限按此顺序）

```text
① 三分法放主体 + 一件对角配平物（改 2 个坐标）
② 景深分层（改 6 个颜色）
③ 所有线指向同一消失点（改 1 组坐标）
④ 逆光剪影 + 3 层轮廓光
⑤ 颗粒 + 暗角 + 暖冷分离
→ 前三条纯构图、后两条光影收尾，**分开做，不要混在一起调**。
```

### 8.8 踩过的坑

- 远山**必须用二次曲线 + 变化的峰宽**（等间距折线出来是廉价锯齿三角）；
- 天空渐变**至少 8 段**（4-5 段在 1920 宽下能看到色带）；
- 中心对称是**零容错**的：任何一处不对称都会被读成"歪了"，要么全镜像要么别用；
- 轮廓光偏移方向必须和主光源一致，否则整个场景的光照逻辑会崩。

### 8.9 可复用工具（实验产出，各 HTML 顶部自包含）

```text
castle(cx, baseY, scale, opts)  参数化建筑（换色即换阵营）
knight(x, baseY, scale, opts)   参数化角色
ridgeLine(baseY, amp, seed, color)  山脊（二次曲线 + 变化峰宽）
haze()                          雾带（垂直渐变）
outlinePath() + rim()           剪影 + 轮廓光
```

## 9. 手作感：有控制的不完美（实验验证，2026-10-10 绘制实验 e096-e100）

### 9.0 总纲

**"精致"不来自"更准确"，而来自有控制的不完美。**
每次观感跃升，都是引入一种**受控的偏差**：线宽起伏 / 色版偏移 / 颗粒 / 纸纤维 / 手抖。
每种都有**甜点区，超过就崩**——不完美的"量"比"有没有"重要。

**"AI 味"的头号来源 = 均匀描边**（同几何同配色，只把 `lineWidth` 常量换成"沿路径起伏的宽度"，档次立刻差一级）。

### 9.1 手绘抖动（性价比第一名）

```text
不改几何/配色/构图，只改绘制方式：矢量贴纸 → 手绘插画
配方：低频正弦(0.6) + 次谐波(0.25) + 小幅 hash(0.35)，freq ≈ 1.8-2.6
幅度阶梯：0px 死板 / 1.4px 自然 / 3.4px 更"手" / 9px 散架
```

**两条致命约束（漏了就到处裂口，比不抖还难看）**：
- **端点必须钉住**（否则线条从形状上脱开）；
- **闭合形状首尾必须重合**（描边时把点列绕回一圈并关掉 taper，否则接口处突然变细出现缺口）。

**频率比幅度关键**：纯 hash 抖动 = 电噪/锯齿，极廉价；必须**低频**。

### 9.2 变宽描边（压感）

```text
① 恒定宽度        → 像 UI 图标 / CAD 线框
② 只做两端收笔    → 有起收笔，中段仍呆板
③ 压感曲线 + 抖动 → 中段鼓、两端尖、走向微晃 → 像笔 ★
甜点：±45%；超过 ±60% 开始崩
```

**幅度要按笔画语义分配**（长笔画大、短零件小），全场同幅 = 廉价滤镜。
实现：点列沿法线偏移生成"变宽带子"再 fill，宽度沿路径起伏。

### 9.3 套色偏移（印刷感）

```text
全部秘密：黑主版偏移恒为 0
  黑版锚定、彩色版绕它漂 → 读作"印刷工艺"
  所有版都偏              → 读作"重影/故障"
偏移 3-6px（随画布缩放），四个方向要散开不能同向
```

实现：每块印版独立离屏 canvas，整版平移后贴回。
**注意：此手法只对特写/近景有效，远景完全看不出来。**

### 9.4 胶片颗粒

```text
必须 overlay + 128 中灰：overlay 的数学性质决定它在纯黑纯白处不变化，
颗粒只出现在渐变/中间调里 —— 正好对应真实胶片。
白黑噪点用 source-over 无论多低 alpha 都显脏（暗部加白点 = 沙眼）。
强度 α ≈ 0.12-0.16；细 + 粗双层最"有物质"。
```

### 9.5 纸张质感（四件事叠起来，缺一件就只是"脏"）

```text
① 纸纤维     必须【各向异性】（y 方向频率取 x 的 3-4 倍）
             各向同性噪声 → 砂纸/雪花；横向拉长 → 立刻读作纸
② 颜料沉积
③ 边缘吃色   同一形状抖动 3 次叠加填充得"毛边" + 内侧描深色当水痕 rim
             （比纸纹本身更关键）
④ 凹凸受光   用高度场沿光照方向的梯度做明暗：
             h(x-1, y-0.6) − h(x+1, y+0.6)
             只加噪声的纸是"平的脏"，加了梯度才"有起伏"
```

**性能坑**：逐像素 `getImageData/putImageData` 很慢——一次算好高度场复用、纸底缓存，
否则多格 1920×1080 会卡到几十秒。

### 9.6 组合顺序（乘数关系，不是加法）

```text
① 手绘抖动        （必做，性价比最高）
② 变宽描边        （必做，治"AI 味"）
③ 套色偏移        （仅近景/特写）
④ 胶片颗粒        （overlay 128 灰）
⑤ 纸张质感        （选风格时与颗粒二选一，别都上）
```

**通用规律**：颗粒/纸纹/抖动**都要最后加**，加完不要再叠图层（否则被放大或模糊掉）。
