# 技法配方（Technique Recipes）

> video-scheduler v0.1.0 · 配套 `style-catalog.md`。

> **为什么存在**：风格目录给了"这种风格该有什么特征"，但**没给"代码怎么画出来"**。
> 动画14 选了「铜版天文钟·双色套印错版」，却退回画细线几何——因为没人告诉它铜版雕刻怎么用 Canvas 画。
> 本文件把**风格特征 → 渲染技法**逐条翻译，扩展/组合风格前先查这里有没有配方；
> 没有配方的风格，先补配方再选（否则必然退回通用线框）。

## 0. 通用渲染原语（所有配方的地基）

```text
填充 vs 线框     fill() 给体量；stroke() 给轮廓。只有 stroke 没有 fill = 线框图（最常见的失败）
渐变             createLinearGradient / createRadialGradient —— 给明暗与体积
多层叠加         globalAlpha + 多次绘制同一形状（错位/偏移）= 印刷/套印/辉光
混合模式         globalCompositeOperation: multiply(加深) / screen(提亮) / overlay(对比)
裁剪             clip() —— 把纹理限制在形状内（材质贴合的通用手段）
路径曲线         bezierCurveTo / quadraticCurveTo —— 有机形态的唯一出路（线框风格可不用）
噪声扰动         vnoise(x,y,t) 扰动顶点/透明度 —— 手作感、纸张、沸腾
颗粒/纹理        drawImage(噪声图) + 低 alpha + multiply —— 几乎所有"质感"风格都需要
```

**铁律**：如果一个风格"看起来有质感"，那一定是 **fill + 多层 + 混合 + 纹理** 的组合，
**不是** stroke 描边能达成的。纯线框 = 没有质感。

## 1. 印刷 / 雕版类（最常被选、最容易翻车）

### 铜版雕刻 Engraving / Copperplate
```text
核心 = 用【密集平行线】代替填充（不是描边轮廓！）
1. 把要画的形状作为裁剪区（clip）
2. 在裁剪区内画密集平行线：间距 1.5~3px，角度随形体走（受光面线疏、背光面线密）
3. 交叉影线（cross-hatch）：暗部叠加第二组反方向线，形成更深的调子
4. 边缘加深：形状边缘用更密的线 + 更粗的线，形成"刻痕"感
5. 底色用暖黄纸色（#e8dcc0 类），线用深褐（#3a2a1a），不要纯黑
6. 加纸纹颗粒（multiply，alpha 8~15%）
关键：线的密度就是明暗。密度=1/间距。稀疏→亮，密集→暗
```

### 双色套印错版 Misregistration / 2-color Print
```text
1. 同一形状画两遍：第一遍颜色 A（如靛蓝），第二遍颜色 B（如朱红）
2. 第二遍整体偏移 2~4px（随机方向，但每帧保持稳定，不要抖动）
3. 两遍都用 multiply 混合 → 重叠处自然变成第三色（套印感）
4. 可加轻微旋转偏移（0.3~0.8°）更像手工套印不准
5. 加纸张纹理 + 边缘轻微溢墨（形状外扩 1px 的浅色）
```

### Riso 孔版叠印 Riso Duotone
```text
1. 限 2~3 色（荧光粉 + 蓝 + 黄，或单色 + 黑）
2. 每个色版独立：形状 + 偏移 + multiply
3. 颗粒噪声必须明显（Riso 的标志）：alpha 15~25% 的粗颗粒
4. 色版重叠处出现深色（multiply 自然产生）
5. 避免渐变——Riso 是平涂 + 颗粒
```

### 蓝图 / 工程制图 Blueprint
```text
1. 深蓝底（#1a3a5c 类）+ 白/青线（负片感）
2. 线要"技术制图"：等宽细线 + 尺寸标注（箭头 + 数字）+ 剖面线（45° 平行线）
3. 网格辅助线（很淡，alpha 5~10%）
4. 标注文字用等宽字体，小号，密度高
5. 关键：要有"图注"——引线 + 编号 + 图例，这才是工程图不是线框画
```

### 活字排版 Letterpress
```text
1. 字为实体：fill 字 + 压印阴影（字下方偏移 1~2px 的暗色）
2. 油墨不均：字内用噪声纹理 multiply（alpha 10~20%）
3. 纸张底 + 纤维纹理；边缘可有轻微墨晕
4. 字距紧、行距小（铅字排版特征）
```

## 2. 仪器 / 机械类

### 天文钟 / 仪表盘 Astronomical Clock / Instrument Dial
```text
1. 多层同心环：外圈刻度（60 格，每 5 格长）、内圈数字、中心指针
2. 金属质感：径向渐变（中心亮、边缘暗）+ 环形高光（1px 亮弧）
3. 雕刻感：刻度线用"刻痕"画法（暗线 + 旁 1px 亮线 = 凹槽）
4. 磨损：用 vnoise 让部分刻度缺失/变淡（wear 参数）
5. 指针带阴影（偏移 2px 的暗色）→ 有厚度
```

### 擒纵机构 / 齿轮 Escapement / Gear
```text
1. 齿轮 = 圆 + N 个齿（齿用 path 画梯形，不是三角）
2. 齿间阴影：齿根处加暗色扇形 → 立体
3. 中心孔 + 辐条（4~8 根，用线 + 宽度渐变）
4. 金属渐变：径向（中心 #c0a060 → 边缘 #604020）
5. 转动时齿要有"咬合"停顿（不是匀速）
```

### 示波器余辉 Oscilloscope Persistence
```text
1. 磷光绿底（#0a1a0a）+ 亮绿轨迹（#40ff80）
2. 余辉 = 不每帧清屏，而是画一层半透明黑（alpha 0.08~0.15）覆盖 → 轨迹自然衰减
3. 双迹：两条波形，相位差，颜色略不同
4. 网格 + 刻度 + 通道标签（CH1/CH2）
5. 波形用 bezier 平滑连接采样点（不是折线）
```

## 3. 古典绘画类

### 烛光 / 明暗对照 Caravaggio / Chiaroscuro
```text
1. 大面积深色底（不是纯黑，#1a1410 类暖黑）
2. 单一强光源：径向渐变（暖白 → 透明），光锥明显
3. 受光面 fill 暖色，背光面几乎融进背景（对比极强）
4. 边缘光（rim light）：形状一侧 1~2px 亮边
5. 关键：形状要"从黑暗中浮现"，不是画在亮底上
```

### 解剖学图谱 Anatomical Plate
```text
1. 米黄纸底 + 褐色线（铜版感）
2. 结构用交叉影线表现体积（见铜版雕刻配方）
3. 标注引线 + 拉丁文小字 + 编号
4. 多个"图版"排列（plate 1/2/3），每版一个部位
5. 加磨损/污渍（vnoise 低 alpha 斑块）
```

### 彩色玻璃 Rose Window
```text
1. 放射状分区（12~24 瓣），每瓣独立填色
2. 铅条：瓣间 2~3px 深色线（#1a1a1a）
3. 玻璃质感：每瓣内径向渐变（中心亮）+ 高光
4. 透光效果：screen 混合的亮斑叠在玻璃上
5. 中心花窗 + 外围环形，层次分明
```

### 金箔祭坛 Gold-leaf Altarpiece
```text
1. 金底：暖金渐变 + 细密斜纹（金箔拼接感）
2. 金箔反光：随时间缓慢变化的亮斑（screen 混合）
3. 主体用深色勾勒（金底上的人物是暗色剪影 + 少量填色）
4. 分格（polyptych）：多个画面格 + 金色分隔框
```

## 4. 材质 / 触感类

### 纸张纤维 Paper Fiber
```text
1. 底：暖白/米色 + 长纤维噪声（方向性噪声，不是白噪）
2. 纤维用短线段随机散布（每帧稳定，用 hash 而非 random）
3. 边缘毛糙：形状边缘用噪声扰动
```

### 墨渍扩散 Ink Bloom
```text
1. 墨滴 = 多层同心不规则形状（每层用噪声扰动半径）
2. 由内到外：深色核心 → 中调 → 淡色晕开边缘
3. 扩散动画：半径随时间增大 + 边缘抖动（boil）
4. 纸张吸收感：边缘比中心更淡（径向 alpha 渐变）
```

### 沙画 / 骨灰流 Sand & Ash
```text
1. 用粒子系统（数千小点）代替连续形状
2. 粒子有重力 + 摩擦，堆积成形状
3. 边缘松散（粒子密度渐变），不是硬边
4. 背光：粒子在暗底上发亮（screen 混合）
```

### 蜡封 / 印章 Wax Seal
```text
1. 不规则圆形（噪声扰动轮廓）+ 内凹阴影
2. 红色蜡质：深红底 + 高光斑 + 边缘半透明
3. 印纹：凹陷的符号（暗线 + 亮线成对 = 凹凸）
4. 压印动画：先变形后回弹（squash）
```

## 5. 图层 / 错位类（通用手段）

### 双图层错位 Two-layer Misregistration
```text
1. 同一内容画两遍，第二遍偏移（2~6px）+ 不同色
2. multiply 混合 → 重叠区变深
3. 偏移量可随时间变化（模拟印刷机抖动）但必须确定性
4. 用途极广：套印、色差、重影、记忆/回忆（第二层=过去）
```

### 银盐负片 Silver Negative
```text
1. 反相：亮处变暗、暗处变亮（可用 invert 或手动画反相）
2. 高对比 + 银盐颗粒（粗颗粒噪声 alpha 15~25%）
3. 边缘光晕（暗角 vignette + 亮边）
4. 褪色：整体降饱和 + 偏暖/偏青
```

## 8. 构图与深度（实验验证，2026-10-10 绘制实验 e089-e095）

### 8.1 "精致"贵在安排，不在画得多细

同一套形状代码，只改 6 个参数：A 面板像教学示例，C 面板像 PV 分镜。
**构图应做成可参数化的槽位（slot），而不是重画一遍。**

### 8.2 深度的公式（5 个变量必须同时动，缺一就塌）

```text
向天空色混合   72% → 0%（越远混合越多）
明度           高 → 低
饱和度         低 → 高
细节密度       无 → 有
描边           无 → 有
```

- **雾带（haze）被低估最多**：两层之间插一条垂直渐变矩形（3 行代码），
  纯色块叠加立刻从"剪纸拼贴"变成"有空气"；
- **人眼主要靠对比度判距离，不是靠大小**——把前景压成近乎纯黑，比把前景画大有效得多。

### 8.3 轮廓光（rim light）不需要任何光照计算

```text
1. 主体画进离屏 canvas → getImageData 取 alpha
2. 逐行 run-length 拼成 Path2D（剪影 sil）
3. fill(sil ∪ translate(sil, d), "evenodd") 并 clip 回 sil
   → 差集天然就是"背对偏移方向那一侧"的月牙（光该在的地方）
4. 3 层即可：3px 白芯 / 8px 金 / 16px 橙（alpha 0.92/0.42/0.20）
```

**推论（重要）**：剪影 + 轮廓光把"造型辨识度"和"细节量"**解耦**了——
主体内部一个细节都不画，观众仍能读出骑士。
→ **先做剪影测试：剪影读不出的角色，加多少细节都救不回来。**

### 8.4 引导线必须收于一个"值得看"的终点

- 线收在空处比不收更糟；
- 消失点偏右 60% 比正中更有行进感；
- 栅栏/树列这类重复元素是**免费引导线**（间距按透视压缩即可）；
- 主角视线是最强引导线。

### 8.5 极端偏心 ≠ 随便放

主体必须被"钉"在一个可解释的位置，否则读成"画歪了"。
**主体尺寸是最便宜的情绪开关**：同一个城堡，0.66 倍 = 宏伟，0.30 倍 + 大留白 = 孤独。

### 8.6 验收方法（两个独立步骤）

```text
缩到 600px 宽还好看 → 构图过关（构图问题在小尺寸放大）
原图看细节        → 细节过关（细节问题在小尺寸消失）
```

### 8.7 性价比排序（预算有限按此顺序）

```text
① 三分法放主体 + 一件对角配平物（改 2 个坐标）
② 景深分层（改 6 个颜色）
③ 所有线指向同一消失点（改 1 组坐标）
④ 逆光剪影 + 3 层轮廓光
⑤ 颗粒 + 暗角 + 暖冷分离
→ 前三条纯构图、后两条光影收尾，**分开做，不要混在一起调**。
```

### 8.8 踩过的坑

- 远山**必须用二次曲线 + 变化的峰宽**（等间距折线出来是廉价锯齿三角）；
- 天空渐变**至少 8 段**（4-5 段在 1920 宽下能看到色带）；
- 中心对称是**零容错**的：任何一处不对称都会被读成"歪了"，要么全镜像要么别用；
- 轮廓光偏移方向必须和主光源一致，否则整个场景的光照逻辑会崩。

### 8.9 可复用工具（实验产出，各 HTML 顶部自包含）

```text
castle(cx, baseY, scale, opts)  参数化建筑（换色即换阵营）
knight(x, baseY, scale, opts)   参数化角色
ridgeLine(baseY, amp, seed, color)  山脊（二次曲线 + 变化峰宽）
haze()                          雾带（垂直渐变）
outlinePath() + rim()           剪影 + 轮廓光
```

## 9. 手作感：有控制的不完美（实验验证，2026-10-10 绘制实验 e096-e100）

### 9.0 总纲

**"精致"不来自"更准确"，而来自有控制的不完美。**
每次观感跃升，都是引入一种**受控的偏差**：线宽起伏 / 色版偏移 / 颗粒 / 纸纤维 / 手抖。
每种都有**甜点区，超过就崩**——不完美的"量"比"有没有"重要。

**"AI 味"的头号来源 = 均匀描边**（同几何同配色，只把 `lineWidth` 常量换成"沿路径起伏的宽度"，档次立刻差一级）。

### 9.1 手绘抖动（性价比第一名）

```text
不改几何/配色/构图，只改绘制方式：矢量贴纸 → 手绘插画
配方：低频正弦(0.6) + 次谐波(0.25) + 小幅 hash(0.35)，freq ≈ 1.8-2.6
幅度阶梯：0px 死板 / 1.4px 自然 / 3.4px 更"手" / 9px 散架
```

**两条致命约束（漏了就到处裂口，比不抖还难看）**：
- **端点必须钉住**（否则线条从形状上脱开）；
- **闭合形状首尾必须重合**（描边时把点列绕回一圈并关掉 taper，否则接口处突然变细出现缺口）。

**频率比幅度关键**：纯 hash 抖动 = 电噪/锯齿，极廉价；必须**低频**。

### 9.2 变宽描边（压感）

```text
① 恒定宽度        → 像 UI 图标 / CAD 线框
② 只做两端收笔    → 有起收笔，中段仍呆板
③ 压感曲线 + 抖动 → 中段鼓、两端尖、走向微晃 → 像笔 ★
甜点：±45%；超过 ±60% 开始崩
```

**幅度要按笔画语义分配**（长笔画大、短零件小），全场同幅 = 廉价滤镜。
实现：点列沿法线偏移生成"变宽带子"再 fill，宽度沿路径起伏。

### 9.3 套色偏移（印刷感）

```text
全部秘密：黑主版偏移恒为 0
  黑版锚定、彩色版绕它漂 → 读作"印刷工艺"
  所有版都偏              → 读作"重影/故障"
偏移 3-6px（随画布缩放），四个方向要散开不能同向
```

实现：每块印版独立离屏 canvas，整版平移后贴回。
**注意：此手法只对特写/近景有效，远景完全看不出来。**

### 9.4 胶片颗粒

```text
必须 overlay + 128 中灰：overlay 的数学性质决定它在纯黑纯白处不变化，
颗粒只出现在渐变/中间调里 —— 正好对应真实胶片。
白黑噪点用 source-over 无论多低 alpha 都显脏（暗部加白点 = 沙眼）。
强度 α ≈ 0.12-0.16；细 + 粗双层最"有物质"。
```

### 9.5 纸张质感（四件事叠起来，缺一件就只是"脏"）

```text
① 纸纤维     必须【各向异性】（y 方向频率取 x 的 3-4 倍）
             各向同性噪声 → 砂纸/雪花；横向拉长 → 立刻读作纸
② 颜料沉积
③ 边缘吃色   同一形状抖动 3 次叠加填充得"毛边" + 内侧描深色当水痕 rim
             （比纸纹本身更关键）
④ 凹凸受光   用高度场沿光照方向的梯度做明暗：
             h(x-1, y-0.6) − h(x+1, y+0.6)
             只加噪声的纸是"平的脏"，加了梯度才"有起伏"
```

**性能坑**：逐像素 `getImageData/putImageData` 很慢——一次算好高度场复用、纸底缓存，
否则多格 1920×1080 会卡到几十秒。

### 9.6 组合顺序（乘数关系，不是加法）

```text
① 手绘抖动        （必做，性价比最高）
② 变宽描边        （必做，治"AI 味"）
③ 套色偏移        （仅近景/特写）
④ 胶片颗粒        （overlay 128 灰）
⑤ 纸张质感        （选风格时与颗粒二选一，别都上）
```

**通用规律**：颗粒/纸纹/抖动**都要最后加**，加完不要再叠图层（否则被放大或模糊掉）。

## 10. 角色与表情（实验验证，2026-10-10 绘制实验 e016-e030）

### 10.0 核心洞察：表情是数据，不是画

**一张脸 = 一个约 20 个标量参数的向量 P。** 加一个表情 = 加一行数据，**绘制代码 0 行**。

```text
drawFace(expr("confused"))             // 按名字
drawFace(lerpExpr(a, b, t))            // 连续过渡（表情切换动画）
drawFace(expr("neutral", {blush:0.8})) // 临时覆盖单参数
```

调度器只需说"角色此刻是 confused"，绘制层把它翻译成 20 个数字，画面就出来了。
分五层，层间零耦合：**头+发 → 眉 → 眼 → 腮红+嘴 → 特效**。

### 10.1 决定"精致"还是"幼稚"的 6 件事（按收益排序）

```text
1. 统一描边色，且不用纯黑 —— 用偏紫暖黑 #3a2f4d（最重线 #241c33）
   纯黑描边是"幼稚"的第一元凶
2. 变宽度描边（taperStroke）—— 头轮廓"两侧粗、下巴细"，嘴"中间粗两端细"
   约 15 行代码，是"手绘感"的最大来源
3. 阴影不是"变黑"，是"变暗 + 偏冷"
   mix(shade(c, -0.16), "#4a3d78", 0.30) —— 暗部带紫，色块立刻有体积
4. Catmull-Rom 代替 arc —— 20 锚点得有机蛋形脸而非正圆
   jaw 参数是"圆脸 → 长脸"的唯一必要参数
5. 每个部件都要"双层细节"：
   眼睛：整圈细描边 + 上眼睑粗描边（3 倍宽，只描上半圈）
   头发：后发暗色 + 前发亮色 + 一条 34% 透明高光带
   虹膜：上暗下亮渐变 + 16 条 20% 透明放射纹 + 两点高光（一大一小对角）
   —— 几乎看不见，但去掉后画面立刻变"死"
6. 特效画在最外层、允许越出脸轮廓
   一旦被裁进脸里就失去"从外部砸向角色"的语义
```

### 10.2 参数化三条铁律

```text
① 枚举参数必须在 t=0.5 硬切，但必须伴随标量插值（否则会"跳"）
② 参数之间不是独立维度，有【乘积交互项】
   例：lidTop 0.36 + browTilt −20 = 阴森反派；+20 = 疲惫的可怜人
   → 设计参数表必须做交叉验证，不能只做单参数扫描
③ 符号型虹膜（x / spiral）必须走描边，实心填充会糊成一团
```

### 10.3 可复用工具（实验产出）

```text
taperStroke()    变宽度描边（通用，对角色/场景/材质都适用）
shadowOf() / lightOf()  阴影/高光配色（变暗偏冷）
drawFace() / expr() / lerpExpr()  表情系统
分层：头+发 → 眉 → 眼 → 腮红+嘴 → 特效
```

### 10.4 复用建议

`taperStroke()` 与 `shadowOf()`/`lightOf()` 对【角色造型】【场景】【材质】方向同样适用——
它们不是"表情专属"，是**扁平卡通的通用手作感手段**。

## 11. 色彩与光照（实验验证，2026-10-10 绘制实验 e046-e060）

### 11.0 最重要的结论：精致度几乎全部来自着色，不是造型

**同一角色，形状/构图/姿态完全一致，只改着色** → L0 平涂（廉价）→ L3 边缘光+彩描边（成片）。
差距 100% 来自着色。**提升观感最快的方法是改着色，不是改造型。**

### 11.1 让画面从"幼稚"到"精致"的四步（与形状无关）

```text
① 暗面换色相（不是加黑）
② 暗面分两层（暗面 / 核心暗部）
③ 加一条背光侧的暖色边缘光
④ 描边不用纯黑（用暗面色的再加深版）
→ 四步做完，同一个几何造型立刻"成片"。
```

### 11.2 可复用"换色相暗面"公式（HSL）

```text
暗面色    = 受光色相 H + 18~28°（往紫/蓝偏），L × 0.70，S × 0.95
核心暗部  = 暗面再 ×0.78 明度
反射光    = 受光色相 H − 8°（回暖），明度介于暗面与受光面之间
描边色    = 暗面色的再加深版，绝不用 #000
```

### 11.3 暗面取色矩阵（5 底色 × 5 策略，e054）

```text
暖色底（黄/橙/红）→ 阴影必须往紫偏（H+30）★"精致"与"廉价"的分水岭
冷色底（蓝/紫）    → 反而加黑最干净，偏移会让颜色变脏
绿色底            → 用互补（H+180），明暗最有戏剧性
唯一永远错误的     → "去饱和"（它让所有颜色变成水泥）
```

### 11.4 完整配色公式（从一个光色 H0 派生全部）

```text
受光面  H+0    L64 S86   |  暗面      H+24 L35 S72  ★（冷光则 H−22）
中间调  H+9    L53 S80   |  核心暗部  H+33 L22 S68
反射光  H−10   L47 S60   |  高光      H+2  L92 S62
描边    H+30   L14 S52 ★ |  强调色    H+180 L56 S78（只占 10%）
```

规律："暗面永远比受光面更冷"——但**不是固定往紫偏**：暖色底 H+30，冷色底加黑最干净。

### 11.5 三条红线（犯了就一定廉价）

```text
① 用纯黑 #000 描边
② 暗面靠"加黑/去饱和"
③ 全画面饱和度都 > 80%
```

### 11.6 氛围 = 色温差，不是明度差

明度关系与暖光版完全一致，但没有色温分离 → 画面平得像灰度稿。

### 11.7 深度感 = 三个变量同向变化

```text
明度 82% → 16% | 饱和 22% → 50% | 细节 0 → 满
消融实验：去掉明度分层 → 完全糊成一片；去掉色相偏移 → 变灰；去掉细节 → 影响最小
```

### 11.8 实现层面 5 个实用技术点

```text
1. 新月路径（crescentPath）是球体/体积分层的核心基元
   数学事实：明暗交界线在 p = d − R 处，让所有内层按 d 精确排序
2. 剪影的每部分必须独立 beginPath + fill
   否则 Canvas nonzero 缠绕规则会在肩/头/臂重叠处互相抵消（主体变半透明）
3. 边缘光算法：亮色剪影朝光源偏移 6~20px → 深色剪影盖回原位
   偏移量必须随体型缩放（固定像素会让头部被顶出光球）
4. 光照必须"每形状自己的沿光渐变"（取形状中心算光源方向）
   全局渐变会让明暗交界位置全错；半平面 clip 会留硬直边
5. 柔光通用配方 = lighter + 三层模糊（blur30 氛围 / blur11 过渡 / blur4 保形）
   单级模糊要么糊成一片要么像贴纸
```

### 11.9 优先级排序（按投入产出比）

```text
1. 明度分层（骨架）      ← 没这个其他都白搭
2. 暗面换色相            ← 投入产出比最高的一步
3. 暗面分两层（暗面/核心暗部）
4. 背光侧边缘光
5. 描边不用纯黑
6. 冷暖分离（氛围）
7. lighter + 三层模糊（光感）
8. 尘埃/体积光（空气感）
9. 暗角 + 冷暖统一（收住画面）
```

### 11.10 坑

- **Bloom 阈值需按画面调**：有亮边缘光的主体，阈值要抬高（0.60 → 0.72），
  否则主角边缘光会被 Bloom 成白球。

## 12. 角色造型与场景（实验验证，2026-10-10 绘制实验 e001-e005 / e031-e040）

### 12.1 角色造型

```text
· 变宽描边（taper）是角色"活"的关键（与 §10.1 一致）
· 高光不能跟着镜像翻转 —— 左右眼高光必须落在同一侧，
  否则全画面出现两个光源（用 mx = flip ? -1 : 1 修掉）
· 金属感的关键不是渐变，而是「亮带紧挨暗带」的高对比 + 铆钉
  两块矩形紧挨（亮带下缘 = 暗带上缘）形成硬边 → 立刻有"折面/棱"
  肩甲用 smoothPath + tension 0.45（偏折线，不要太圆）
· 绘制顺序：披风必须在躯干之前
```

### 12.2 场景深度的 4 个来源（按重要性）

```text
1. 分层（Layer Separation）—— 画场景前先写 4 行：L0 天空 / L1 远景 / L2 中景 / L3 近景
   每层必须【遮住】下一层的一部分
2. 大气透视 —— 甜点区 40%-55%（远层还能辨认形状但已明显退后）
   雾化必须【层级化】，不能全画面统一加雾（那就只是变淡）
3. 细节密度 ∝ 1/距离（与 §8 一致）
4. 单点透视 —— 灭点必须在视平线上，视平线 = 地平线
   一旦错开，画面立刻"歪"；左右两排树用 t 与 t+0.055 错开，避免"仪仗队"感
```

### 12.3 场景搭建要点

```text
· 接触阴影是"钉住"物体的关键：扁椭圆 rgba(46,66,34,0.16~0.20)，
  ry/rx ≈ 0.13（要扁且浅，深了会脏）
· 远景村庄必须是纯剪影 —— 加描边会让它"跳"到前面，破坏纵深
· 天花板必须画（室内）：不画 = 顶部空掉，室内感消失一半
· 夜空：视线锚点必须靠暖色点（窗火 rgba(255,198,104,1) + 小径向光晕），
  因为整个画面都是冷色
· 火：不要用渐变，用三层"水滴形"色块叠加（#c43a18→#ff9a3c / #e8552a→#ffd75e）
· 光柱必须用 lighter 且只加不遮（不透明光柱会盖住树）
· 同一元件在不同细节等级下必须保持同一"视觉重量"：
  描边宽度固定 4~5px（不随尺寸缩放），大元件才不会有"粗黑边"
```

## 13. 材质与道具（实验验证，2026-10-10 绘制实验 e061-e075 / e076-e088）

### 13.1 材质通用规律

```text
· 频率必须按目标尺寸重调：大图 x*0.024 的 voronoi，
  在 434px 卡片里要用 x*0.024*(1920/434) ≈ x*0.106
· 金属/陶瓷必须额外补镜面高光，玻璃必须额外补斜向反射带
  （它们的"材质身份"主要靠表面反射，逐像素场只能给底色）
```

### 13.2 各材质关键

```text
石墙    块内必须有东西（凹坑带下缘反光 + 裂纹 + 苔痕）
        空白的石块无论怎么打光都是塑料
木纹    纹理位移随形状走，不要平铺
布料    织物感 = 结构 + 光照两件事
        只画格纹（贴图）像塑料布；只有 weave 结构没褶皱像砂纸
        各向异性高光贡献 80% 的"布"感（slope 转法线后与光向点乘）
金属    划痕必须"亮暗各半"（只亮像玻璃，只暗像脏）
玻璃    气泡/波纹/裂纹等"内部杂质"是区分"彩色玻璃"和"彩色色块"的关键
        每块 1~5 个气泡就够
草地    关键不是叶子数量，是"簇"结构
        均匀撒叶 = 均匀绿噪声；改"簇"（根 + 根部阴影 + 扇形分布）立刻有草感
        根部的径向暗斑是让草"扎进地面"的关键
皮革    缝线必须画两次：深色粗线（针孔/阴影）+ 亮色细线（线本身），45° 倾斜
毛皮    = 流场 + 根尖渐变（方向必须由流场统一控制，否则是"杂毛"）
沙地    沙纹必须"非对称"（正半周开 0.62 次方、负半周 1.7 次方 → 缓坡迎风+陡脊背风）
        沙粒噪声频率要接近像素级，且只调亮度不改色相
砖墙    剥落区必须渐隐（上下 destination-out 渐变），否则出现硬边横带
冰雪    雪丘轮廓必须用 fbm 扰动且要"软"（顶部纯白、底部转冷蓝）
马赛克  裂纹必须"盖"在砖上（后画）且带 2px 亮边
```

### 13.3 道具与装饰

```text
· 统一外轮廓（ink-outline）：先把图层所有子形状 stroke() 描一圈粗边（10px），
  再逐个 fill() —— 后填的色块盖住内部描边，只剩外轮廓
  （比"每块都描边"干净，也比"整组后描边"不会出现内部杂线）
· 图层顺序即结构（例：旗帜 = 墙→旗杆→横杆→旗布→边框→内场→交叉剑→盾徽→王冠→装饰带→流苏→挂环→光效）
· 对称纹样程序化：双层循环铺菱形拉扣，行间错位（r%2?21:0），
  每颗由"暗菱形底 + 中亮菱形 + 亮菱形 + 暗圆扣 + 弧形高光"5 层叠成
  ★ 同一颗扣子画 5 层是"贵"的关键，单层菱形只是图案
· 贝塞尔求值贴装饰：把臂的 cubic bezier 写成函数 bez(t,i)，
  取 t=0.46 求点 + 用相邻两点差分求切线角 atan2(dy,dx)
  ★ 曲线上的装饰必须求值（位置+角度），不能目测
· 发光体的"光"必须画在它之外：只画火焰 = 贴纸；
  在台面/柱身/墙面各补一层受光 → "暗室里的烛光"
  ★ 光晕是被照亮的物体，不是火焰的光圈
· 边框不能只有一条：三条粗细不同（28→15→10）+ 颜色交替 = "画框"
· 细节密度必须服从视觉层级：主体区域的纹理应比背景更克制
  （反例：地毯纹理强度=墙面 → 地毯比王座还抢眼）
· 视觉重点 = 主体 + 周围一圈空（陈列品必须先留位再排书，否则被淹没）
· 纹样必须可数（随机跳过 30% 格子 → 看起来像"脏点"不是"纹样"）
```

### 13.4 材质统一公式（E 组总结，12 种材质验证）

```text
材质 = 颜色场 + 3 个尺度的结构 + 光 + AO + 颗粒
```

12 种材质的差异**全部**落在这 5 项的取值上。**缺任何一层都会得到"塑料感"**：

```text
大尺度（低频 fbm，multiply 混合）→ 斑驳、脏污、干湿
中尺度                          → 砌块 / 裂纹 / 凹坑 / 细胞 / 褶皱 = 材质的"身份"
高频（grain / hashi）           → 颗粒噪点（overlay，幅度 0.055~0.085，几乎免费）
定向光（左上暖、右下冷暗）+ 底部 AO + 暗角
```

**中尺度必须"不规则"，否则一定像瓷砖/网格**（本次最大的坑）：
- **domain warp（坐标扭曲）是最有效的武器**——锈蚀第一版直接采样 voronoi 得到规则龟裂，
  加 `wx = x + fbm(...)*520-260` 后立刻成立；
- 砌块要有角缺口 + 尺寸抖动；砖要 ±3~7px 抖动 + 圆角；马赛克 ±1.2px 形状抖动；
- **各向异性**是区分材质的关键：冰内裂横向拉长（`x*0.0052, y*0.0018`）、
  皮纹椭圆（`x*0.155, y*0.115`）、金属拉丝在极坐标下采噪声。

**浮雕/压印 = 同一路径画三遍**：
```text
(dx,dy)=(5,6) 填暗 → (-4,-5) 填亮 → (0,0) 填中性
纯代码做压印最省最准。
```

**统一接口**（12 种材质可共用）：
```text
fn(x, y, w, h) → [r, g, b]
★ 频率必须按目标尺寸重调（大图技法缩印到小卡片时不重调 = 一块均匀色）
```

## 14. 渲染工程坑（实验验证，2026-10-10）

```text
① Canvas 对无效颜色值【静默忽略】——写错 hex 会出奇怪颜色但不报错
② Canvas 报错后画面只剩背景，很难从截图反推错误
   → 必须用 page.on("pageerror") 监听（实验写了 checkall.mjs 批量检查）
③ 剪影的每部分必须独立 beginPath + fill（nonzero 缠绕会互相抵消，主体变半透明）
④ 逐像素 getImageData/putImageData 很慢 → 一次算好高度场复用、纸底缓存
⑤ Bloom 阈值需按画面调（有亮边缘光的主体要抬高 0.60→0.72）
⑥ 缩放必须最近邻（像素风）／避免抗锯齿糊边
```

## 15. 深度感的优先级与量化参数（实验验证，2026-10-10 绘制实验 e031-e045）

### 15.1 深度感有明确优先级（不是并列的）

```text
① 分层 + 遮挡（有没有空间）      ★★★★★
② 明度阶梯（分不分得开）        ★★★★★
③ 大气透视 / 雾化（远不远）      ★★★★
④ 前景画框（是不是镜头）         ★★★★
⑤ 描边随距离衰减（精不精致）     ★★★
⑥ 透视（空间合不合理）           ★★★
⑦ 细节密度（耐不耐看）           ★★
```

**①②不做，③~⑦全做也白搭。** 很多人一上来就堆细节，结果还是"平"。

### 15.2 "精致"的可操作定义

```text
精致 = 单位面积内的"决策数量"，不是"线的数量"
排序：明暗层次 > 描边 > 纹理线 > 元素数量
```

- 给树冠加"暗面 clip + 高光 clip"只需 2 行，立刻从贴纸变球体；
- 而多画 100 根草提升最弱。

### 15.3 三个可直接抄的参数

```text
明度阶梯：相邻层感知明度差 0.13~0.20（ΔL < 0.07 就糊在一起）；4 层是实际上限
描边档位：天空/远山 0px → 远景 0~2px → 中景 2~3.5px → 近景 3.5~7px
        描边色用"环境暗色"（深棕 #3a2a18 / 深绿 #1e3324），绝不用纯黑
雾化：   L1 0.72 / L2 0.32 / L3 0.10 / 前景 0.0（向天空色 mix）；甜点 40~55%
```

### 15.4 透视只是一个除法（20 行引擎）

```js
// 室外
y(t) = 地平线 + (画面底 - 地平线) * t^1.85
scale(t) = 230 * (1 - t) + 16
// 室内（关键复用模式）
Y(u) = VPY + BK*u;   YC(u) = VPY - WH*u;   X(xb, u) = VPX + (xb - VPX)*u;   // u=1 后墙
```

**所有物体只用 (深度, 底边x, 尺寸) 三个参数描述，透视自动正确。**
非线性 t（幂次 1.5~2.0）比线性重要得多。

### 15.5 五个反复踩的坑

```text
1. 分层顺序：地面必须先于树绘制；同一深度层内部也有顺序
   顺序错 = 树被地面吃掉
2. 前景框不能用复杂多边形：自交会把画面吞成一片黑 → 拆成独立矩形/四边形
3. 剪影的边界必须被细节打碎：实心暗块 + 稀疏草 = 死黑一片
   要"轮廓函数 + 沿轮廓生长的密草"
4. 多层三角必须"整棵实体三角 + 内部阶梯"，否则层间漏背景形成 V 形亮缝
5. 针叶树宽高比 ≈ 1:1.05，做成细高就变"尖刺森林"
```

### 15.6 场景可复用架构

```text
场景 = 构件函数(level) × 摆放(深度u) × 缩放(scale(u)) × 雾化(haze(u))
```

**"精致"可以量化成一个整数参数 level**：
level 0 几何体 → level 2 建筑构件，差别只有"多一条描边、多一层明暗、多一个配件"。

### 15.7 快速出效果的建议

```text
· 想快速出好看场景：【先画黄昏】—— 天空自带 6 级明度阶梯，天然满足 ①②
· 单一暖光源 + 大量冷色背景 = 色彩对比核心
  暖色点状光（窗火/烛火）是唯一视线锚点
· 暗角用 createRadialGradient(w/2, h*0.5, h*0.22, w/2, h*0.5, h*0.78)
  用 h 做半径基准，暗角才集中在四角
· 云隙光/丁达尔光柱必须 lighter 且 alpha ≤ 0.15，只加不遮
```

## 16. 「精致 vs 幼稚」的 6 个变量（实验验证，2026-10-10 A 组 e012 核心结论）

同一角色、同尺寸、同构图，只切换 5 个变量 → A（幼稚）/ B（中等）/ C（精致）三级对照。

### 16.1 按影响力排序的 6 个变量

```text
第 1 名：描边的【宽度变化】，而不是宽度本身
        恒定 lineWidth → 线框图/图标；变宽描边（taper）→ 手绘
        实现：折线采样成密集点 → 沿法线左右偏移 w(t)/2 → 多边形填充
        w(t) 用 sin(πt) 做中段隆起，两端收到 0

第 2 名：描边色不用纯黑
        #000 → #3a2b33（暖紫黑）。纯黑会让暗部"死掉"、画面变脏
        ★ 描边色应该 = 画面暗部色，而不是黑；且随背景变

第 3 名：头身比
        3.4 → 6.0 是"卡通小人"和"角色"的差别
        注意：不是越写实越好；达拉崩吧那类风格在 4.5-5.5
        ★ 关键是头不要超过身高的 1/4

第 4 名：体积感用「裁剪内偏移椭圆」而不是渐变
        sideShade()：把路径 clip 起来，在内部画一块偏移的暗色椭圆
        比渐变快、边界"平"符合扁平卡通调性、位置可控（光从左上来→暗椭圆放右下）

第 5 名：眼睛的信息量
        黑点 → 眼球 → 完整结构，信息量差 10 倍
        最小可用组合：巩膜 + 虹膜（暗外环+亮内环）+ 瞳孔 + 1 大 1 小两高光 + 变宽上眼线

第 6 名：不对称
        对称的脸 = 图标；不对称的脸 = 角色
        刘海 3 束不等宽、发梢高度不同 —— 成本几乎为零，收益极大
```

### 16.2 一句话总结

> **精致 = 变宽描边 + 非黑描边色 + 克制的头身比 + 裁剪式体积感 + 高信息量的眼睛 + 刻意的不对称。**

### 16.3 反直觉的发现（重要）

- **细节密度不是越高越好**：精致版的细节集中在"头发高光 / 眼睛 / 衣服暗面"三处，
  其他地方（裤腿、鞋子）反而比幼稚版更简洁。**细节要有预算，花在视觉焦点上。**
- **幼稚版的问题不是"画得少"，而是"画错了"**：
  13px 纯黑等宽描边比 7px 变宽描边**多用了近一倍墨水**，却更幼稚。
  ★ 所以"加粗描边让它更醒目"是错误直觉。

### 16.4 角色制作的其他要点（A 组补充）

```text
· 转头 = 中轴偏移 + 眼睛投影 + 轮廓不对称，三者必须同时做（少一个就穿帮）
  五官里【鼻子】最能体现转头：正面只是一个点，侧面必须画出完整鼻梁+鼻尖
· 剪影可读性测试：wrap.fillStyle = SIL; wrap.strokeStyle = SIL;
  ★ 否则裸 fill() 会用上一次遗留的颜色（踩过的坑）
· 耳朵必须"长在头轮廓之外"
· 职业家族 = 一个骨架 + 多张配置表
· 配色克制：主色只出现 1 次（上衣），点缀色只出现 2-3 处（领口/鞋底/腰带扣）
· 描边色必须随背景变（暗背景上要用比背景更亮的金色高光才读得出轮廓）
· 模型表：正面和四分之三可复用同一套 headPath，但【侧面必须单独写轮廓】
  ★ 不要为每个视图写一份代码（否则改了正面忘了改侧面）
· 角色互动：两人的视线延长线必须在画面内相交
  ★ 这是"他们在互动"而不是"两个贴纸"的根本
```

### 16.5 头身比数值表（身份的第一信号）

```text
3.0 = 幼儿 | 4.0 = 矮人 | 5.4 = 小孩 | 6.2 = 成人
★ 同样的脸、同样的描边，只改头身比，年龄感就变了
★ "幼稚"最大的来源不是画得简单，而是【用了儿童比例】
达拉崩吧那类风格在 4.5-5.5；关键是头不超过身高 1/4
```

### 16.6 描边色随背景变（具体值）

```text
浅暖底 → #3a2b33（暖紫黑）
深冷底 → #161a26
浅粉底 → #6b4a58
★ 深底上描边不能比背景更暗，否则角色糊成一团
```

### 16.7 剪影优先（先设计剪影再填细节）

```text
能靠剪影认出的角色，靠的是【外挂物】：
  王冠锯齿 / 肩甲方角 / 尖帽 / 长弓 / 大锤
★ 不是身体——身体剪影其实都差不多
★ 先做剪影测试，剪影读不出的角色加多少细节都救不回来
```

### 16.8 细节预算：每角色只给 2-3 个高辨识度标志物

```text
标志物示例：王冠 / 面甲 / 大胡子 / 围裙
把细节预算集中花在标志物上，其余概括
★ 精致 ≠ 每处都细，而是【细节密度有对比】
```

### 16.9 绘制顺序铁律（违反则"头浮空"）

```text
后臂 → 后腿 → 披风/尾巴 → 躯干 → 前腿 → 前臂 → 脖子 → 头
★ 脖子必须画到【头的中心】被头盖住，否则任何姿态都"头浮空"
```

### 16.10 两层复用结构（参数化的最终形态）

```text
基元层（跨角色复用）：taper / ribbonPath / headPath / torsoPath /
                      eye / limb / plate / sideShade / groundShadow
骨架层（同角色复用）：pose() 关节表 → drawHero()
★ 参数化后"画 6 个姿态"和"画 1 个姿态"成本几乎一样
```

### 16.11 工程坑（角色库特有）

```text
· paint() 漏传 ctx 会把颜色字符串当 ctx 用 → 加防御自动补 activeCtx
· eye() 被误用位置参数会【静默丢参数】 → 加防御
· Canvas 对无效颜色静默忽略（写错 hex 只出异常色块，不报错）
· Canvas 报错后画面只剩背景，从截图无法反推 → 必须监听 pageerror
```
