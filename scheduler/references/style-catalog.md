# 风格目录（Style Catalog）

> video-scheduler v0.1.0 · 用于 §1.4(2) 的**总体风格候选库**与**技术路线参考**。
> 来源：[mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)（MIT，Vincentwei1021）——
> 15 种 motion design 风格，每种由 Claude Opus 5.5 从一句 prompt 写代码做出（无图像/视频生成，纯代码）。
>
> **用法**：这是**种子**不是清单——风格候选可从这些**扩展**，也可组合；
> 每种给出「视觉特征 / 关键技法 / 技术路线」，照着做能命中该风格，而不是只写个名字。

---

## 1 · 扁平矢量 Flat / Vector 2D
- **视觉特征**：纯色大色块、几何化角色、无渐变或极少渐变、干净留白、高饱和品牌色板、元素弹性入退场
- **关键技法**：弹性缓动是灵魂——overshoot 用 `cubic-bezier(0.34,1.56,0.64,1)`；入场"预备-冲出-回弹"三段式；元素错峰入场（stagger 2~4 帧），同一时刻只让一个主体动；位移带 ~10% squash&stretch
- **技术路线**：SVG + GSAP（CustomEase/CustomBounce/MorphSVG）；快动作加 motion blur

## 2 · 线条动画 Line Art
- **视觉特征**：等宽细线、单色或双色、大量负空间、线条连续生长、线面转换瞬间
- **关键技法**：核心是 stroke 描绘（Web 端 `stroke-dasharray/dashoffset`）；线宽全片恒定（2~4px）；"一笔画"叙事——上一图形尾线即下一图形起线；线转面=描完轮廓后 fill 从锚点扩展
- **技术路线**：SVG paths + `stroke-dashoffset` + GSAP；虚拟摄像机跟随笔尖

## 3 · 等轴 2.5D Isometric
- **视觉特征**：30° 等角投影、无透视灭点、微缩场景、楼房生长动画、平行滑轨式运镜
- **关键技法**：SSR 公式造等轴面（Scale 纵向 86.6% → Shear ±30° → Rotate ∓30°）；假 3D 靠图层排序（Z 序 = 画面 y 坐标）；楼房"生长"=底面落位 + scaleY 拉起 + 顶面延迟 2~3 帧；运镜=整组平移，前中后景视差 1:0.8:0.6
- **技术路线**：Three.js OrthographicCamera 真等角 + 软阴影/AO；或 SVG 矩阵面

## 4 · 3D 渲染 3D Render / CGI
- **视觉特征**：PBR 真实材质、浅景深、柔和棚拍布光、克隆器阵列、软体碰撞、糖果色软胶质感
- **关键技法**：MoGraph 核心=Cloner + Random/Plain Effector 做群体波浪动画；质感三件套=SSS 次表面散射 + AO + HDRI 三点布光；运动用长尾 ease（前 20% 走完 80% 路程）；24/25fps 电影帧率 + 浅景深
- **技术路线**：Blender CLI（bpy → Cycles/EEVEE）→ PNG 序列 → ffmpeg；可选 HTML 叠字层

## 5 · 逐帧手绘 / 线条沸腾 Cel / Frame-by-Frame & Line Boil
- **视觉特征**：线条持续微抖（boil）、一拍二/一拍三节奏、smear 拖影帧、手绘烟火水花点缀、纸纹底
- **关键技法**：打帧节奏（24fps 下"一拍二"为主，快动作切"一拍一"，静止"一拍三"）；boil 伪造=3~4 个抖动变体每 2 帧轮换；纸纹 multiply 10~15%
- **技术路线**：Canvas2D 自定义变宽笔刷（中心线+压力→轮廓多边形）+ 纸纹 multiply

## 6 · 拼贴剪贴 Collage / Cutout
- **视觉特征**：照片剪影白描边、半调网点、报纸纹理、比例失衡的超现实拼装、定格式抽帧运动
- **关键技法**：素材抠图 + 2~4px 白描边 + halftone 滤镜；关节动画（锚点设肩/肘/颌，puppet 式分段旋转）；刻意降帧 12fps 甚至 6fps + ±2px 随机抖动模拟手摆；图层=背景纸纹→大形色块→照片剪影→涂鸦贴纸→颗粒
- **技术路线**：DOM/Canvas + PNG 抠图 + SVG/CSS 白边与半调；步进 12fps（30fps 渲染、12fps 网格保持）

## 7 · 液态流动 Liquid Motion
- **视觉特征**：波浪边缘转场、拉丝与滴落、metaball 融合、次级液滴跟随、有机曲线永不直线
- **关键技法**：metaball 伪造法=高斯模糊(20px+) → 提高对比度阈值（两球靠近自动"粘连"）；拉丝-断裂-回弹（离开时留细颈，断裂瞬间两端各回弹 2~3 帧）；缓动前快后慢 `cubic-bezier(0.22,1,0.36,1)`
- **技术路线**：WebGL2 fragment shader——2D SDF metaballs（smooth-min）+ 场梯度法线伪 3D 光照

## 8 · 形变 Morphing / Shape Morph
- **视觉特征**：轮廓连续过渡无跳变、中介形状桥接、形变伴随位移旋转、变形瞬间挤压拉伸
- **关键技法**：路径对齐是前提（顶点数一致、首顶点对应，否则打结）；复杂 A→B 不直接变——先收敛为中介简形（圆/胶囊）再展开，"A→圆→B"两段各 8~12 帧；全程叠 10~15% squash&stretch 掩盖插值机械感；速度中段最快 `cubic-bezier(0.7,0,0.3,1)`
- **技术路线**：SVG + flubber 或 GSAP MorphSVGPlugin（调 shapeIndex）+ 色场擦除

## 9 · 几何构成 / 包豪斯 Bauhaus
- **视觉特征**：基础几何形、红黄蓝黑限定色、严格网格对齐、旋转以几何中心为轴、节拍驱动的模块化运动
- **关键技法**：一切运动锚定网格（位移=网格模数整数倍，落点在网格线）；缓动克制（easeInOutQuad 或匀速，**禁用 overshoot**——机械感是特征）；节拍驱动（一拍一个动作）；旋转轴心玩法（自身中心/边缘顶点/画面中心交替）
- **技术路线**：SVG/Canvas + GSAP，严格模块化网格，节拍网格 120 BPM

## 10 · 复古 80s Synthwave / VHS / Y2K
- **视觉特征**：霓虹辉光、透视网格地平线、扫描线与 RGB 色偏、镀铬金属字、酸性配色、拟物窗口 UI
- **关键技法**：synthwave 三件套（透视网格滚动 + 日落多层渐变球 + 双层辉光）；VHS 做旧链（RGB split 各偏 1~2px → 扫描线 2px/10% → 波浪扭曲随机 glitch → 4:3 圆角遮罩）；Y2K 镀铬字（多段金属渐变 + bevel + 环境映射）；Y2K 运动语言=弹窗式 pop、光标点击、窗口拖拽
- **技术路线**：WebGL（透视网格/太阳/山 shader）+ canvas 镀铬字 + CSS/SVG 辉光 + VHS pass

## 11 · 弥散渐变 / 玻璃拟态 Aurora & Glassmorphism
- **视觉特征**：大色斑高斯模糊漂移、磨砂玻璃卡片、1px 高光描边、邻近色低对比、缓慢呼吸节奏
- **关键技法**：底层 aurora=3~5 个纯色大圆 blur 80~150px 沿贝塞尔路径 20~40s 漂移；玻璃卡片配方=`backdrop-filter blur(20~40px)` + 白 5~10% 填充 + 1px 白 30% 内描边 + 大圆角；配色用邻近色 2~3 色（撞色会脏）；全局 3~5% 噪点防 banding
- **技术路线**：WebGL（aurora mesh-gradient shader + 玻璃折射）+ DOM/CSS `backdrop-filter` 卡片

## 12 · 综艺花字 Variety Show Kinetic Captions
- **视觉特征**：多层描边圆体/胖体字、高饱和撞色+白边+投影、弹性 pop 入场、配合音效、手绘装饰符号（爆炸框/汗滴/闪光）
- **关键技法**：字体三层结构（填充色 + 粗白描边 + 彩色外描边/投影）；入场 overshoot（scale 0→1.15→1.0 约 8 帧，或逐字弹跳错帧 2 帧）；情绪匹配（吐槽→歪斜手写体、惊讶→放射线、尴尬→汗滴）；出现时机对齐笑点/音效，比语音晚 2~3 帧更自然
- **技术路线**：DOM/SVG 多层 text-stroke 组件 + spring pop + SVG 装饰符号，叠在实拍层上

## 13 · 粗描边贴纸科普 Bold-outline Sticker Explainer
- **视觉特征**：照片贴纸化（粗白描边）、蓝灰/米白冷静底色、扁平图标+精确图表、大画布镜头平移缩放、信息密度极高的节拍化叙事
- **关键技法**：照片抠图 + 8~12px 白描边统一质感（消除来源差异）；超宽大画布布局 + 摄像机层平移/缩放（长 ease），一镜串多个信息点；图表动效（柱状生长、数字滚动、路径描边）；解说词逐句驱动元素入场
- **技术路线**：一张超大 canvas（如 6000×3000）+ 摄像机变换 + SVG 图表 + 照片贴纸（10px 白边）

## 14 · 像素风 Pixel Art / 8-bit
- **视觉特征**：大颗粒像素与硬边缘、有限色板（8~32 色）、8~12fps 精灵帧动画、抖动渐变 dithering、CRT 扫描线
- **关键技法**：精灵表 + 序列帧循环（走路 6~8 帧、呼吸 2~4 帧）；缩放必须**最近邻插值**（`image-rendering: pixelated`），杜绝抗锯齿糊边；动画用 `steps()` 阶梯时序而非平滑缓动；视差卷轴背景（远中近三层不同速度整像素平移）
- **技术路线**：Canvas 内部 320×180、整数倍放大 ×6 + 最近邻；精灵用代码里的像素数组；受限色板

## 15 · 赛博朋克 HUD / FUI
- **视觉特征**：青/橙霓虹线框、目标锁定框与十字准星、雷达/环形扫描 loop、等宽小字数据流与打字机文字、六边形网格与辉光
- **关键技法**：线框生长（`stroke-dasharray/dashoffset` 描边动画，元素按层级错帧展开）；环形雷达（`conic-gradient` 扫描扇区旋转 loop + 目标点闪烁）；数字滚动（随机数跳变 3~5 帧后落定真实值）；锁定框（四角括号 scale 1.4→1.0 + 快出缓入）
- **技术路线**：SVG/Canvas FUI 层 + Three.js 线框全息 + 种子随机数据 + 辉光/扫描线后期

## 使用方式（接 §1.4(2) 总体风格）

```text
1. 从本目录 15 种 + 意象分析结论，扩出 20-50 个候选（可组合，如"包豪斯 × 像素风"）；
2. 筛 5-20 个（标序号）→ 三维打分（素材贴合/意图贴合/可实现性）→ 最高分 2-3 个内随机定 1；
3. 定稿后：把该风格的「视觉特征 / 关键技法 / 技术路线」写进 style-bible，成员照此执行；
4. 局部风格（§1.5 颗粒度）可从其他风格借"镜头语言/节奏/材质"，但主世界观不换。
```

**注意**：本目录是**技法参考**不是模板——同一种风格在不同歌里应长成不同样子；
照抄某支片子的具体构图 = 换标签，不是创作。
