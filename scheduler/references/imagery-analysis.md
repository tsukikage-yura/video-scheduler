# 意象分析（Imagery Analysis）

**为什么存在**：直接对"词汇表"选风格会把**载体词误当意象**——歌词里的术语、名词、技术词是【载体】，
不是主题本身。只按字面选视觉，画面会与歌的情感内核错位。

---

## 1. 两条路径（按素材量分）

### 路径 A：素材少（一句话 / 一个标题 / 模糊需求）→ 主体联想

```text
1. 抓主体
2. 联想 2-3 个候选所指，并标出假设——不单方面锁定一个
3. 列出相关信息 → 审查缺什么关键资料 → 缺失则联网搜集；必要时向用户确认假设
4. 资料齐了再想两件事：
   · 文案（打分：表面意思 ≤50 / 文案美感 ≤40 / 多重可解读 ≤10，合计 100）
   · 演出形式（把需求翻成可视过程，并补细节）
```

### 路径 B：素材多（MV：歌 + 歌词）→ 深层涵义解析（**默认必做**）

```text
1. 先读完整歌词
2. 不要以"我觉得我懂了"跳过——用客观信号触发联网查证（见 §4）
3. 判别"载体词 vs 意象"（见 §2），追问术语/技术词象征什么
4. 反例检验（见 §2）：只按字面做，歌的情感还成立吗？不成立 = 字面误读，重做
5. 结合所有信息解析 → 产出意象分析文档（落盘）
```

---

## 2. 载体词 vs 意象（核心判别）

| | 载体词（surface） | 意象（image） |
| --- | --- | --- |
| 是什么 | 歌词里出现的术语 / 名词 / 技术词 | 它象征的情感 / 关系 / 命运 |
| 特征 | 可替换成同义词而主题不变 | 换掉它主题就变了 |
| 误用 | 看到词就选对应视觉（词→图 直译） | —— |

**两条检验**：
- 反向：把载体词换成同义词，歌的情感变了吗？**没变** → 它们是载体，不是主题；
- 正向：只按字面做视觉，歌的情感还成立吗？**不成立** → 字面误读，必须重做。

---

## 3. 文案打分（仅用于意象分析 / 文案，**不用于画面**）

```text
表面意思   ≤ 50   能一眼看懂在讲什么（地基）
文案美感   ≤ 40   措辞 / 结构 / 节奏好看（工艺）
多重解读   ≤ 10   有层次、可回味（加分项）
──────────────────
合计       100
```

---

## 4. 客观触发信号（满足任一 → 必须联网查证）

```text
- 专有名词 / 术语 / 技术词密集
- 双关、谐音、多语言混排
- 文化 / 宗教 / 历史引用
- 歌名是句子片段或非常规短语
- 专辑 / 创作者有已知背景或系列关联
- 你的理解与"字面直译"高度重合（最危险：以为懂了）
```

---

## 5. 门槛与衔接

- 无意象分析文档 → **风格决策不合格**；
- 每个风格候选必须能回答"这个风格如何承载主题"；
- 意象分析产出是后续**制作分工方案**的输入（先读懂，再分工）。

---

## 6. 软规则：主体风格的颗粒度

```text
主体风格 = 大方向，只锁三样：
  · 色调（palette）
  · 演出主体维度（2D / 2.5D / 3D / 混搭）
  · 世界观基调
其余（镜头语言 / 节奏 / 材质 / 局部风格）在分工细化时再定。

避免风格过度统一：主段不能是同一个镜头反复拍——
主风格锁世界观，局部允许在镜头语言 / 节奏 / 材质上变化。
```
