# G2 分层与视差（e116–e130）方向总结

15 个实验，全部基于同一套"2.5D 合成器"：7 个绘制层 → 每层独立离屏 canvas →
施加 (雾化 fogK / 压暗 dim / 模糊 blurK) → 按深度 p 施加视差位移 → 合成。
**只改变"深度参数"，不改变场景内容**，因此每个面板的差异都可归因到具体参数。

## 实验清单

| 编号 | 主题 | 结论一句话 |
|---|---|---|
| e116 | 层次分离 0/1/3/6 段 | 0→3 段是唯一质变；1 段≈0 段；3 段是够用线 |
| e117 | 前景遮挡比例 | 12%~20% 才像镜头，18%（两侧各 168px）最稳 |
| e118 | 视差量 panX | 判据是层间错位；≥20px 才读得出，90px 是甜点 |
| e119 | 视差速率分布 p | 两段式（远焊死+中景突跳）最像镜头；线性等分最差 |
| e120 | 景深 DOF | 中景必须最锐；虚化是加强项不是必需项 |
| e121 | 推轨动画 | 同一堵墙上的元素必须同 p，否则一动就露馅 |
| e122 | 遮挡的位置与形状 | 面积相同观感可完全不同；非对称最"活" |
| e123 | 主体对位 | 角色占画面 1/3；被前景切到腰 = 最强"在场感" |
| e124 | 有框 vs 无框 | 两条黑边 = 从"插画"变"镜头"；框必须配视差 |
| e125 | 硬边/软边/破碎边 | 前景框加 4~6px 模糊 = 最快的纵深作弊器 |
| e126 | 前景框自己的 p | p=0.88~0.92 才让框从"UI 边框"变"场景柱子" |
| e127 | 层间亮度阶梯 | 远亮近暗是最硬的深度线索，比模糊更有效 |
| e128 | 层数够不够 | 绘制层数 ≠ 深度段数；4 段是最高性价比进阶 |
| e129 | 反例 | 均匀模糊/缩放冒充纵深/前景过暗无光 = 三种假 2.5D |
| e130 | 综合推荐参数 | 结论帧（含 UI），参数见 notes/e130.md |

## 最终推荐参数

```js
far:   { p: 0.05, fogK: 0.55, blurK: 2.4, dim: 0.00 }  // sky + farwall + colonnade
midg:  { p: 0.40, fogK: 0.14, blurK: 0.6, dim: 0.08 }  // midarch + mid(角色/提灯/光柱)
front: { p: 0.90, fogK: 0.00, blurK: 1.6, dim: 0.22 }  // nearprops(栏杆/大飞页) + frame(装饰柱)
panX = 90px    前景框宽 168px（遮挡 18%）    frameStyle = 'pillar' | 'arch'
```

## 六条核心结论（"怎么做才能像原神那种画面"）

1. **纵深必须来自"层与层的关系"，不能来自对单层做变换。**
   雾差 + 明度差 + 速度差 + 虚化差，四个差一起给，方向一致（越远越雾、越亮、越不动、越虚）。
2. **先做明度阶梯，再做虚化。** 远亮近暗是最硬的深度线索，零性能成本；虚化是加强项。
3. **中景必须最锐、最实、对比最强。** 景深是用来隔离主体的，氛围交给雾。
4. **前景框要"半实"**：够黑够实（#03050c）+ 4~6px 模糊 + 金色描边 + p 0.88~0.92。
5. **遮挡是构图工具，不只是纵深工具。** 非对称/单侧/顶横带都在改构图；
   原神过场里前景框几乎总是非对称的，这是"电影感"的来源。
6. **压暗前景之后必须给前景留一个光源**（提灯暖光/金色描边），否则前景死掉。

## 一句话
> **2.5D 的"2.5"不在几何里，在"层与层之间的四个差"里。**
> 几何只要分对三层（远墙 / 中景主体 / 近景遮挡），剩下的全部交给雾差、明度差、速度差、虚化差。
> 这四个差一致了，画面就"深"了；再加上非对称前景框和一点暖色突破，就是原神过场的那种画面。

## 自检清单
- 转成灰度还能读出纵深吗？（检验空气透视是否够）
- 层间错位 ≥20px 吗？（检验视差是否有效）
- 中景是最锐的那一层吗？（检验景深是否正确）
- 压暗的前景上有光吗？（检验前景是否死掉）
- 同一堵墙上的元素在同一个 p 上吗？（检验推轨会不会露馅）
