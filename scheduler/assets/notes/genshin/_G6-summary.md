## 可复用配方
```
1. far   天空渐变 + 月亮 + 云带 + 地平线暖光 + 远城剪影 + 星点
2. wall  evenodd 打洞 → 石缝 + 拱券线脚 + 窗台 + source-atop 洞口阴影 + 竖棂
3. fog   下浓上淡的蓝色雾（加在 wall 与 mid 之间！）
4. mid   地面 + 每窗一道冷光池 + 柱（柱头金星）+ 檐部 + 光柱 + 提灯 + 角色
5. 粒子  飞鸟 → 浮尘 → 花瓣 → 书页（远中近三档）
6. near  前景画框柱 + 焦外光斑 + 上下压暗条
7. bloom 两次 blur 叠加（72px α0.76 / 24px α0.50）
8. grade multiply 暗角 → overlay 冷暖 → lighter 暖脚光 → 胶片颗粒
9. UI    对话框 + 左侧圆形选项按钮
```

## 明度校验（最终帧）
| 层 | 亮度 |
|---|---|
| 窗口内天空 | ~110 |
| 柱子中段 | ~70 |
| 墙体 | ~27 |
| 地面 | ~17 |
| 前景画框 | ~7 |

**近景比远景暗 15 倍。这是纵深感的真正来源，不是视差。**

## 对 BRIEF 假设的验证
BRIEF 假设"几何化 + 平涂 + 分层 + 冷暖 足以复刻"——
**基本成立，但必须补第 5 条：值域控制（value control）。**

原神画面的真正特征不是"元素多"，而是**每一层的明度被严格约束**：
远景不允许超过某个亮度，近景不允许亮于某个亮度。
初版 e176 失败的根本原因就是窗口天空过曝到接近纯白（亮度 200+），
与角色的白衣撞在一起，画面瞬间失去纵深。

## 工程踩坑（全部致命）
1. `destination-out` 会连天空一起擦掉 → 打洞必须用 **evenodd**
2. `beginPath()` 清空多子路径 → 必须拆 `archSub`（无 beginPath）/ `archPath`
3. opaque fill 会盖住洞口 → 洞口阴影只能用 `source-atop`
4. 雾画在 far 内部会被墙盖住 → 必须在 composite 阶段、墙之后、mid 之前
5. 前景光斑 α 过高会变灰色圆盘 → 降到 0.065 并做冷暖分化
6. 近景书页会挡住主角 → 减到 3 片、α 0.20
7. 地面光楔硬边 → 用径向渐变椭圆代替梯形多边形
8. 画框柱花纹做成半圆会像月牙 → 改成 S 形双曲线 + 圆点 + 尖叶
