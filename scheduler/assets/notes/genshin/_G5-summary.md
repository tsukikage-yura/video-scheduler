# G5 角色处理（e161-e175）结论汇总

## 15 个实验
| 编号 | 内容 | 结论 |
|---|---|---|
| e161 | 纯剪影 | 肩宽必须 ≥1.8× 头宽，否则是"幽灵圆锥" |
| e162 | 剪影+双边缘光 | **边缘光必须 clip 在剪影内**，否则变霓虹管 |
| e163 | 几何化立绘全身 | 兜帽是从肩线长出的整体形状 |
| e164 | 侧身/行走 | 披风并入轮廓环后缘，不做独立形状 |
| e165 | 背影剪影 | 兜帽用 clip 内内部形状，不画浮空椭圆 |
| e166 | 远小角色(H=150) | **只留剪影+边缘光，内部细节全删** |
| e167 | 细节阈值阶梯 | **H<200px 细节主动损害画面** |
| e168 | 兜帽:头 比例扫描 | **1.35× 最佳**，0.9=针尖头 2.15=蘑菇 |
| e169 | 半身特写(3/4背) | 开口椭圆推出兜帽边界 → clip 自动切出月牙 |
| e170 | 正面脸可行性 | **无可用尺寸区间**：大=clip-art，小=糊 |
| e171 | 三人构图 | 尺度+模糊+明度+遮挡 = 景深 |
| e172 | 前景遮挡 | 内缘暗边是"画框感"的关键 |
| e173 | 光柱打角色 | 角色先压暗，光柱再提亮，避免烧白 |
| e174 | 逆光 vs 顺光 | **逆光剪影性价比最高** |
| e175 | 推荐配方 | 完整合成帧 |

## 能 / 不能（诚实边界）
✅ 剪影、双边缘光、兜帽斗篷形、背影/3-4背影/侧身、远景小角色、平涂+cel、金饰、光柱、逆光
⚠️ 大尺寸几何化正面脸 → 读作通用 clip-art，不是原神
❌ 原神精度手绘正面脸、复杂姿态、手部、表情演出

## 最终配方（可直接复用）
- 轮廓：Catmull-Rom 闭合样条，肩宽 0.120H，裙摆 0.196H
- 兜帽：宽 1.34× 头宽，高 1.42× 兜帽宽，底边压肩线
- 面部：**3/4 背影，零五官**（暗腔 + 一弯受光脸颊 + 下颌线）
- 细节分级：H>300 全细节 / 150-300 去褶皱去五官 / <150 只留剪影+边缘光
- 边缘光：clip 到剪影内 + 半平面裁剪，左冷右暖，垂直渐变
- cel 阴影：硬边曲线多边形（不要渐变、不要直线）
- 图层：夜空 → 拱窗 → 地面+光池 → 角色 → 光柱 → 提灯 → 飞页/花瓣/浮尘 → 前景立柱 → UI

## 核心洞察
原神过场的角色之所以"看起来对"，不是因为我们画不出那张脸，
而是因为**原神自己也很少把脸放在画面的信息重心上**——
它用背影、逆光、剪影、远景，以及**角色与光的关系**来讲故事。
**我们能用代码复刻的，正是这一层。**
