## 最关键的发现

### 1. 材质 = 颜色场 + 3 个尺度的结构 + 光 + AO + 颗粒
12 种材质的差异**全部**落在这 5 项的取值上。缺任何一层都会得到"塑料感"：
- **大尺度**（低频 fbm，multiply 混合）：斑驳、脏污、干湿
- **中尺度**：砌块 / 裂纹 / 凹坑 / 细胞 / 褶皱 —— 材质的"身份"
- **高频**：颗粒噪点（`grain` / hashi）
- 再叠定向光（左上暖、右下冷暗）+ 底部 AO + 暗角

### 2. 中尺度结构必须"不规则"，否则一定像瓷砖/网格
这是本次最大的坑，反复踩到：
- **domain warp（坐标扭曲）** 是最有效的武器。锈蚀 e071 第一版直接用 voronoi → 规则龟裂；加 `wx = x + fbm(...)*520-260` 后立刻成立。
- 石墙的砌块要有**角缺口 + 尺寸抖动**；砖墙要有 ±3~7px 的尺寸抖动 + 圆角；马赛克砖要有 ±1.2px 形状抖动。
- **各向异性**是区分材质的关键：冰的内裂要横向拉长（`x*0.0052, y*0.0018`），皮纹要椭圆（`x*0.155, y*0.115`），金属拉丝要在极坐标下采噪声。

### 3. 高频"颗粒"是精致的必要条件，且几乎免费
一层全屏 `grain()`（overlay 混合，幅度 0.055~0.085）就能把"干净的矢量图"变成"有质感的画面"。沙粒要接近像素级频率（×1.55）；布料绒毛要 ×1.7。**没有这一层，任何材质都像塑料。**

### 4. 结构单元必须有"倒角"和"接触阴影"
每个砖/石/瓦内部画左上亮线 + 右下暗线（2~5px），体积感立刻出来。每个结构单元下方要有接触阴影。这比任何渐变都有效。

### 5. 反射决定"表面身份"
金属/陶瓷/玻璃的身份主要靠**表面反射**，不是靠底色：
- 金属：抽象环境（上亮 + 一条亮带 + 一条暗带）+ 菲涅尔边光
- 粗糙度 = 高光半径与强度（同一球换两个参数就能从镜面读到哑光）
- 玻璃：透光 + 铅条（结构）+ 斜向反射带，三者缺一不可

### 6. 生物/植被材质要用"簇"而不是"粒子"
草地第一版均匀撒 1200 片叶 → 均匀绿噪声。改成"簇"（共享根部 + 根部径向暗斑 + 扇形分布）后立刻有草地感。**根部的暗斑是让草"扎进地面"的关键。** 毛皮同理：流场统一方向 + 每束共享走向。

### 7. 浮雕/压印 = 同一路径画三遍
`(dx,dy)=(5,6)` 填暗色 → `(-4,-5)` 填亮色 → `(0,0)` 填中性色。纯代码做压印最省最准（e067 徽记）。

### 8. 把材质抽象成 `fn(x,y,w,h) → [r,g,b]`
e075 证明这个签名可以统一 12 种材质。**建议作为素材库的接口**。注意：频率必须按目标尺寸重调，不能照搬大图参数。

## 踩过的坑（工程教训）
1. **Canvas 对无效颜色值静默忽略**。写错一个 hex（`'#b09madd'`）会导致出现品红色物体，不报错。要在截图里留意异常色。
2. **Canvas 报错后画面只剩背景**，很难从截图反推。必须用 `page.on('pageerror')` 监听（`build/checkall.mjs`）。
3. **循环变量作用域**：`tiles.forEach(t => ...)` 里误用外层的 `h3` → 整个画面只剩灰缝。
4. **大图技法缩印到小卡片时必须重调频率**（e075 的 K 换算）。
