## ★ 最关键的发现（怎么做才能让画面精致）

### 1. 描边的**宽度变化**，比描边宽度本身重要得多
恒定 `lineWidth` 是"幼稚感"的头号来源，**比造型本身影响还大**。
把折线采样成密集点 → 沿法线左右偏移 `w(t)/2` → 多边形填充，
`w(t)` 用 `sin(πt)` 做中段隆起、两端收到 0 —— 立刻从"线框图"变成"手绘"。

> **反直觉**：e012 的 A 版（13px 纯黑等宽）比 C 版（7px 暖黑变宽）**多用了近一倍墨水**，
> 却更幼稚。所以"加粗描边让它更醒目"是错误直觉。

### 2. 描边色**绝不用纯黑**
`#000` → `#3a2b33`（暖紫黑）。纯黑让暗部"死掉"、画面发脏。
**描边色 = 该画面暗部的主色调**，并且必须随背景变：
- 浅暖底 → `#3a2b33`
- 深冷底 → `#161a26`
- 浅粉底 → `#6b4a58`
- **深底上描边不能比背景更暗**（否则角色糊成一团），要靠亮色高光勾轮廓。

### 3. 头身比是身份的**第一信号**，比任何细节都重要
| 3.0 | 3.4 | 4.0 | 5.4 | 6.2 |
|---|---|---|---|---|
| 幼儿 | 幼稚卡通 | 矮人 | 小孩/国王 | 成人 |

"幼稚"最大的来源不是画得简单，而是**用了儿童比例**。
注意：不是越写实越好，达拉崩吧那类风格在 4.5–5.5 之间；关键是**头不要超过身高的 1/4**。

### 4. 体积感用「裁剪内偏移椭圆」，不要用渐变
`sideShade()`：把路径 clip 起来，内部画一块**偏移的暗色椭圆**。
比渐变快、边界"平"（符合扁平卡通调性）、位置可控（暗示光向）。

### 5. 细节要有**预算**，花在标志物上
每个角色只给 2–3 个高辨识度标志物（王冠/面甲/大胡子/围裙），把细节预算集中花在那里；
其余部位可以很概括。**"精致"≠ 每个地方都细，而是细节密度有对比。**
e012 的 C 版细节只集中在"头发高光 / 眼睛 / 衣服暗面"三处，裤腿鞋子反而比 A 版更简洁。

### 6. 眼睛的信息量决定"成熟度"
黑点 → 眼球 → 完整结构，信息量差 10 倍。最小可用组合：
**巩膜 + 虹膜（暗外环 + 亮内环）+ 瞳孔 + 1 大 1 小两个高光 + 变宽上眼线**。
⚠️ **左右眼高光不能跟着镜像翻转**，否则全画面出现两个光源。

### 7. 不对称 = 角色；对称 = 图标
刘海 3 束不等宽、发梢高度不同，成本几乎为零，收益极大。

### 8. 剪影优先：先设计剪影，再填细节
e009 证明：能靠剪影认出来的角色，靠的是**外挂物**（王冠锯齿 / 肩甲方角 / 尖帽 / 长弓 / 大锤），
不是身体。身体剪影其实都差不多。
检查清单：肩线是否和外挂物形成不同角度？有没有至少一个**超出身体轮廓 30%** 的元素？

## 可复用资产

### 两层复用结构（重要）
1. **基元层（跨角色）**：`taper / ribbonPath / headPath / torsoPath / eye / brow / mouth / limb / plate / sideShade / groundShadow`
2. **骨架层（同角色）**：`pose()` 关节坐标表 → `drawHero(cx, footY, S, P)`

参数化之后，**"画 6 个姿态"和"画 1 个姿态"的成本几乎一样**。
跨角色共享的是基元，不是骨架。

### 关键函数签名
```js
K.taper(g, pts, w0, w1, color, {mid, pow, wFn})   // 变宽描边（本方向最重要的工具）
K.limb(g, pts, w0, w1, fill, stroke, lw)          // 变宽胶囊肢体
K.sideShade(g, pathFn, cx, cy, rx, ry, col, a)    // 裁剪内偏移椭圆（体积感）
K.headPath(g, x, y, w, h)                         // 蛋形头
K.torsoPath(g, cx, topY, botY, {top,waist,bot})   // 三段式躯干（有腰线）
K.eye(g, {x,y,rx,ry,style,iris,look,lid,lashes})  // 5 种眼型
K.groundShadow(g, x, y, rx, ry, col, a)           // 径向渐变投影
```

### 绘制顺序（肢体遮挡的通用规则）
后侧手臂 → 后侧腿 → **披风/尾巴** → 躯干 → 前侧腿 → 前侧手臂 → **脖子（画到头部中心）** → 头
> 脖子必须一直画到头的中心，被头盖住 —— 否则任何姿态都会"头浮空"。

## 踩过的坑（工程教训）
1. **`K.paint()` 漏传 ctx**：`paint(fill, stroke, lw)` 会把颜色字符串当 ctx 用。已加防御（自动补 activeCtx）。
2. **`K.eye()` 被误用 `eyes()` 的位置参数**：`eye(g, x, y, opts)` 会静默丢参数 → 眼睛不画。已加防御。
3. **Canvas 对无效颜色静默忽略**：写错 hex 不报错，只会在图上出现异常色块。
4. **必须监听 `pageerror`**：Canvas 报错后画面只剩背景，从截图无法反推。用 `_check.mjs`。
5. **Proxy 做剪影时要显式初始化 `fillStyle`**，否则裸 `fill()` 会用上一次遗留的颜色。
